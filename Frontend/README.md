# Moodify Frontend

The React and Vite frontend for Moodify. For full-stack setup, Docker Compose,
and environment configuration, see the [repository README](../README.md).

## Local development

```sh
npm ci
npm run dev
```

Vite runs at [http://localhost:5173](http://localhost:5173) and proxies API
requests to `http://localhost:3000`.

## Checks

```sh
npm run build
npm run lint
```
